# Clef scan rulings

The lead's verdict on each flag of the Clef scan (`scripts/clef_scan.py`, CONTRIBUTING.md "Clef
scan"), one row per flag, newest last. The key identifies the flag's likeliest line by its file
and the five lines around it, so a ruled flag is not raised again while that code is unchanged.
The scan report prints each new flag's row with the verdict and reason left to fill in. A `|`
inside a reason is written `\|`.
