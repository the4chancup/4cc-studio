The first run asks where your settings and data live. `Next to the program`
puts them in a `data/` folder beside `UnlimitedToolWorks.exe`. This is fully
portable, because the folder carries the program and everything it keeps, and
deleting it removes both.

`In my user folder` puts them in `%APPDATA%\4cc-studio` on Windows or
`~/.config/4cc-studio` on Linux, so the data survives deleting or replacing the
program folder.
