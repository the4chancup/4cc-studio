The first run asks where your settings and data live. `Next to the program`
puts them in a `data/` folder beside `4cc-studio.exe`: fully portable, so the
folder carries the program and everything it keeps, and deleting it removes both.

`In my user folder` puts them in `%APPDATA%\4cc-studio` on Windows,
`~/.config/4cc-studio` on Linux: the data survives deleting or replacing the
program folder.
