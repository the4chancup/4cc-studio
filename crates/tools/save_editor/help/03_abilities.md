The **Abilities & Skills** tab holds the player's gameplay card: registered position,
playing style, stronger foot and hand, form, injury resistance, weak foot usage and
accuracy, the playable positions with their C/B/A ratings, the ability stats, and
his skills and COM playing styles.

The numbers are the game's own, the same ones the game's Edit mode shows: abilities
run 40 to 99, form 1 to 8, weak foot 1 to 4. A value the save holds
outside a range shows as stored; it changes only when you edit it.

A greyed control is one the save's PES version does not have: hover it and the
tooltip names the first version that does (for example PES 19+). The same fields
stay in the same places on every version, so the tab never rearranges.

**Cards left** counts the paid cards the player has left under each tier of the
AATF rules in use (the rules file chosen in the settings menu's Save editor
section, else the built-in official rules): the skills and COM playing styles
that count against the tier's limit.
The number goes red when he holds more than the limit. When the rules file does
not load, the error shows in the badges' place instead.
