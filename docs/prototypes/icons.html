Icon drafts for the shell font

One icon per tool gets picked here; the picked SVGs then feed the fontTools build that replaces the interim Phosphor subset. Every candidate keeps the font's drawing convention: a 256 grid, 16-unit round strokes, nothing outside 16..240, one colour.
