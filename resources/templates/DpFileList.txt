# The official 4cc DpFileList, as a list: one CPK per line, in load order (a later CPK's
# files win over an earlier one's). Lines starting with # are comments.
#
# Fixed by the maintainer on 2026-10-03. `DpFileList.bin` is written from this list (the
# same file for every PES version) and embedded as the DpFileList upgrade's template, and
# every compile compares the installed list with it.
#
# The numbering: a run of CPKs with one stem counts from 1 (`4cc_41_teams`, `4cc_61_midcup`).
# The stadiums run counts from 0, because its first CPK is the base one and the stadium
# midcups follow it. Each kind of midcup has fifteen CPKs, one per matchday of the longest
# cups.
