Unlimited Tool Works 0.0.1
==========================

A test version, for DBC's testers. If anything goes wrong or reads strangely, tell us: that
is what this version is for.

This version is the Save editor, on the left bar. The other tools there are greyed out,
because their windows come in a later version.


The first time
--------------

1. Unpack this archive into a folder of its own, anywhere you like.
2. Open UTW.exe. It keeps its settings in the data folder beside it, so
   everything it needs stays in this one folder.
3. The window starts on PES 2017, the game DBC is played on. If the PES box on the left bar
   turns yellow or red, click the gear at the bottom of the bar (Settings) and set
   "PES folder" to the folder that holds the game's PES2017.exe.


Checking a team for DBC
-----------------------

The Save editor checks teams against DBC7's rules from the start: every cup's current rules
are built in, so there is nothing to set up. To check against another cup's rules, pick them
in the dropdown on the Save editor's toolbar, left of Live AATF.


When something goes wrong
-------------------------

Every message names a code, such as fpc_custom_skin_on_non_fpc. The help explains each one:
open UTW.exe and click the ? at the bottom of the left bar.

If a problem stops you, edit your save as usual, and tell us what happened.
